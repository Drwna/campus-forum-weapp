## 项目简介

CampusHub 是一个校园论坛平台，由三个独立项目组成：

| 项目 | 技术栈 | 用途 | 端口 |
|---|---|---|---|
| `server/` | Express + TypeScript + Prisma | 后端 API 服务 | 3001 |
| `admin/` | Vue 3 + TypeScript + Element Plus | 管理后台 | 5173 |
| `miniapp/` | uni-app + Vue 3 + JavaScript | 微信小程序 | 5174 |

### 技术栈一览

```
前端（小程序）          前端（管理后台）           后端
├── uni-app 3          ├── Vue 3                ├── Express 4
├── Vue 3              ├── TypeScript           ├── TypeScript
├── Pinia              ├── Element Plus         ├── Prisma 7
└── JavaScript         ├── Pinia                ├── MySQL 8
                       └── Vite                 ├── Redis 7
                                                └── ioredis
```

## 快速开始

### 第一步：环境准备

确保已安装以下工具：

```bash
# 检查 Node.js 版本（需要 18+）
node --version

# 检查 pnpm（用于 server 和 admin）
pnpm --version

# 检查 npm（用于 miniapp）
npm --version
```

### 第二步：启动依赖服务

```bash
# 进入项目根目录
cd campus-forum-weapp_2

# 启动 MySQL 和 Redis
docker-compose -f deploy/docker-compose.dev.yml up -d

# 复制环境变量模板
cp .env.example .env
```

### 第三步：启动后端服务

```bash
# 进入 server 目录
cd server

# 安装依赖
pnpm install

# 生成 Prisma 客户端
pnpm prisma generate

# 执行数据库迁移
pnpm prisma migrate dev

# 填充种子数据（创建管理员账号、分类等）
pnpm prisma db seed

# 启动开发服务器
pnpm dev
```

启动成功后会看到：
```
Server running on port 3001
API base path: /api/v1
```

### 第四步：启动管理后台

```bash
# 新开终端，进入 admin 目录
cd admin

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

访问 http://localhost:5173，使用管理员账号登录：
- 账号：`admin`
- 密码：`ChangeMe_123456`

### 第五步：启动小程序

```bash
# 新开终端，进入 miniapp 目录
cd miniapp

# 安装依赖
npm install

# 启动 H5 开发模式（浏览器调试）
npm run dev:h5
```

访问 http://localhost:5174 即可在浏览器中预览小程序。

## 核心概念

### 1. 分层架构

后端采用四层架构：

```
请求 → Routes → Controllers → Services → Repositories → 数据库
         ↓           ↓            ↓            ↓
       路由定义    参数校验     业务逻辑     数据访问
```

- **Routes**：定义 URL 路径和 HTTP 方法
- **Controllers**：解析请求参数，调用 Service，返回响应
- **Services**：实现业务逻辑（唯一的业务逻辑层）
- **Repositories**：封装数据库查询

### 2. 数据库模型

使用 Prisma ORM，模型定义在 `prisma/schema.prisma`：

```prisma
// 示例：用户模型
model User {
  userId       BigInt    @id @default(autoincrement())
  nickname     String
  avatar       String?
  role         Int       @default(0)  // 0=学生, 1=审核员, 2=管理员
  status       Int       @default(0)  // 0=正常, 1=禁用
  createTime   DateTime  @default(now())
  // ...
}
```

### 3. 认证流程

```
微信小程序登录：
1. 用户点击"微信一键登录"
2. 调用 wx.login() 获取 code
3. 发送 code 到后端 /api/v1/auth/wechat-login
4. 后端用 code 换取 openid
5. 创建/更新用户记录
6. 返回 JWT token

管理员登录：
1. 输入账号密码
2. 发送到 /api/v1/auth/admin-login
3. 验证密码（bcrypt）
4. 返回 JWT token
```

### 4. 权限控制

```typescript
// 角色枚举
enum UserRole {
  Student = 0,    // 普通学生
  Moderator = 1,  // 审核员
  Admin = 2,      // 管理员
}

// 路由保护示例
router.get("/admin/posts", 
  requireAuth,                    // 必须登录
  requireRole(UserRole.Admin),    // 必须是管理员
  controller.getList
);
```

### 5. 错误处理

```typescript
// 错误码格式：4位数字，前2位是模块
enum ErrorCode {
  UserNotFound = 1001,      // 用户模块
  PostNotFound = 2001,      // 帖子模块
  CommentNotFound = 3001,   // 评论模块
  // ...
}

// 抛出错误
throw AppError.badRequest(ErrorCode.PostNotFound, "帖子不存在");

// 统一响应格式
{
  "code": 2001,
  "message": "帖子不存在",
  "data": null,
  "traceId": "xxx"
}
```

## 开发指南

### 添加新功能的步骤

以"添加举报功能"为例：

#### 1. 定义数据库模型

```prisma
// prisma/schema.prisma
model Report {
  reportId     BigInt   @id @default(autoincrement())
  reporterId   BigInt   // 举报人
  targetType   Int      // 1=帖子, 2=评论
  targetId     BigInt   // 被举报内容ID
  reasonType   Int      // 举报原因类型
  status       Int      @default(0)  // 0=待处理
  // ...
}
```

#### 2. 执行数据库迁移

```bash
pnpm prisma migrate dev --name add-report
```

#### 3. 创建模块文件

```
server/src/modules/report/
├── report.dto.ts       # 数据传输对象（参数校验）
├── report.routes.ts    # 路由定义
```

#### 4. 定义 DTO（参数校验）

```typescript
// report.dto.ts
import { z } from "zod";

export const CreateReportSchema = z.object({
  targetType: z.number().int().min(1).max(2),
  targetId: z.string().min(1),
  reasonType: z.number().int().min(1).max(6),
  reasonText: z.string().max(500).optional(),
});

export type CreateReportDTO = z.infer<typeof CreateReportSchema>;
```

#### 5. 实现路由

```typescript
// report.routes.ts
import { Router } from "express";
import { requireAuth } from "../../middleware/index.js";

const router = Router();

router.post("/", requireAuth, async (req, res, next) => {
  try {
    const dto = CreateReportSchema.parse(req.body);
    // 业务逻辑...
    success(res, { reportId: "1" }, req.traceId);
  } catch (error) {
    next(error);
  }
});

export default router;
```

#### 6. 注册路由

```typescript
// app.ts
import reportRoutes from "./modules/report/report.routes.js";

app.use(`${basePath}/reports`, reportRoutes);
```

## 问题排查

### 问题 1：数据库连接失败

```
Error: Can't connect to MySQL server
```

**解决方案：**
```bash
# 检查 MySQL 是否运行
docker ps | grep mysql

# 启动 MySQL
docker-compose -f deploy/docker-compose.dev.yml up -d mysql

# 检查 .env 配置
cat server/.env
```

### 问题 2：Redis 连接失败

```
Error: Redis connection failed
```

**解决方案：**
```bash
# 检查 Redis 是否运行
docker ps | grep redis

# 启动 Redis
docker-compose -f deploy/docker-compose.dev.yml up -d redis
```

### 问题 3：端口被占用

```
Error: listen EADDRINUSE :::3001
```

**解决方案：**
```bash
# 查找占用端口的进程
lsof -i:3001

# 终止进程
kill -9 <PID>
```

### 问题 4：Prisma 客户端未生成

```
Error: @prisma/client did not initialize yet
```

**解决方案：**
```bash
cd server
pnpm prisma generate
```

### 问题 5：TypeScript 类型错误

```bash
# 运行类型检查
cd server
pnpm typecheck

# 或
cd admin
pnpm typecheck
```

## 代码规范

### 命名规范

- **文件名**：kebab-case（如 `user.service.ts`）
- **变量/函数**：camelCase（如 `getUserById`）
- **类/接口**：PascalCase（如 `UserService`）
- **常量**：UPPER_SNAKE_CASE（如 `MAX_IMAGE_SIZE`）
- **数据库字段**：snake_case（如 `user_id`）
- **API 字段**：camelCase（如 `userId`）

### 提交规范

```
类型(范围): 描述

feat(user): 添加用户注册功能
fix(auth): 修复登录失败问题
docs(readme): 更新文档
style(lint): 修复代码格式
refactor(post): 重构帖子查询逻辑
test(unit): 添加用户模块测试
```
